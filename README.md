# Pró3 Academia — Site

Site institucional responsivo para a **Pró3 Academia**, com apresentação da rede, unidades, modalidades, planos e informações de contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Tailwind CSS via CDN
- Font Awesome

## Páginas e arquivos

```text
index.html       página principal
unidades.html    unidades
privacy.html     privacidade
404.html         página de erro
styles.css       estilos adicionais
script.js        interações
img/             imagens
```

## Execução local

Abra `index.html` no navegador ou use um servidor local para testar o site.

## Publicação

O repositório está configurado para uso com GitHub Pages.
